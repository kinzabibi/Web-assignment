##Cozy Café Website ☕

A simple and responsive café website created using **HTML, CSS, and JavaScript**.

## Features
- Home page with café introduction.
- Specials section displaying coffee, cakes, and pastries.
- About section with Read More functionality.
- Menu with item prices and filtering options.
- Order form with customer details.
- Light/Dark mode toggle.
- Interactive JavaScript features.

##Technologies Used
- HTML
- CSS
- JavaScript

## Images
The website includes images of coffee, cakes, pastries, and the café.

## Project
This project was created as a web development assignment to practice HTML, CSS, and JavaScript.
