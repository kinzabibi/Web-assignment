# ☕ Cozy Café Website

A simple and responsive café website developed using **HTML, CSS, and JavaScript**. This project was created as a web development assignment to provide an interactive online café experience where users can explore café specials, browse the menu, learn about the café, and place orders.

##Features

- Home page with café introduction.
- Specials section displaying coffee, cakes, and pastries.
- About section with Read More functionality.
- Menu with item prices and filtering options.
- Order form with customer details.
- Light/Dark mode toggle.
- Interactive JavaScript features.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

##Images

The website includes images of coffee, cakes, pastries, and the café.

## 🚀 How to Run the Project

You can view the live project directly here:

**Live Demo:** https://kinzabibi.github.io/Web-assignment/

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.

*Note: For the best experience, use a modern browser like Google Chrome or Mozilla Firefox.*
